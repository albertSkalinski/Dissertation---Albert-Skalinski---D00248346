# Albert Skalinski - Dissertation

What Musical Features Drive Song Popularity? A Time Series Analysis.



This project contains the following structure:

* data - raw and cleaned datasets
* notebooks - Jupyter notebooks for EDA and modelling
* scripts - Python scripts for data processing and model training
* models - saved trained models
* outputs - final results
* docs - MD documentation
* README.md - project overview; the file you're reading now
* requirements - dependencies list
* .gitignore - a specification for intentionally untracked files for Python that Git should ignore
